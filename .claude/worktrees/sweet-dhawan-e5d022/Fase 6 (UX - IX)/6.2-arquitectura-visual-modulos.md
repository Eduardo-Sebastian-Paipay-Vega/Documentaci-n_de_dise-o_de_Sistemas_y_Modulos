### 2.3 Componentes del Dashboard

| Componente | Datos que muestra | Módulo origen |
|------------|-------------------|---------------|
| KPI Cards (fila) | Voluntarios totales, activos hoy, pendientes, alertas stock | ong, rrhh, inventario |
| Actividades de hoy | Lista de actividades de la fecha actual | ong.actividades |
| Aprobaciones pendientes | Admisiones y gastos esperando acción | rrhh, finanzas |
| Proyectos activos | Proyectos con barra de progreso | ong.proyectos |
| Finanzas del mes | Resumen income/expense/balance | finanzas.transacciones |

- 11–12: ámbar (aprobado mínimo)
- ≤10: rojo (reprobado)

## 16. PATRONES DE NAVEGACIÓN ENTRE MÓDULOS

### 16.1 Breadcrumb contextual

Todo flujo de múltiples niveles muestra un breadcrumb en el topbar:
```
Proyectos › Campaña Salud 2026 › Actividades › Jornada Médica II › Asistencia
```

### 16.2 Command Palette (Ctrl + K)

Búsqueda global con acceso rápido a:
- Personas (voluntarios, beneficiarios por nombre o DNI)
- Proyectos y actividades
- Transacciones por monto o referencia
- Acciones rápidas ("Crear actividad", "Registrar gasto")
- Módulos del sistema

### 16.3 Panel lateral (Side Sheet)

Para acciones frecuentes sin abandonar la pantalla actual:
- Ver perfil rápido de voluntario (desde cualquier lista)
- Registrar movimiento de inventario
- Ver detalle de notificación
- Previsualizar comprobante

### 16.4 Breadcrumb de módulo activo

El sidebar siempre muestra resaltado el módulo activo con el color de módulo correspondiente
(ver tokens `--mod-*` en el documento 6.1).
