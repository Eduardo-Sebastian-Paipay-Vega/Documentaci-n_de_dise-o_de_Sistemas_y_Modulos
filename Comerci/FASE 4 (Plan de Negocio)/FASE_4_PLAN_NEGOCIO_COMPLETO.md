## 📈 UNIT ECONOMICS DETALLADO

### Customer Acquisition Cost (CAC)

**Year 1 Breakdown**:
```
Marketing budget:           $2.0M
Usuarios adquiridos:        25,000
CAC = $2.0M / 25K =        $80/usuario

Por canal:
├─ Organic/Viral:  40% usuarios, $0 CAC
├─ Paid (Google):  35% usuarios, $120 CAC
├─ Partnerships:   25% usuarios, $60 CAC

Weighted CAC:               $56/usuario
```

**Year 3 Projection**:
```
Marketing: $15M (más eficiente)
Usuarios adquiridos: 180K
CAC = $15M / 180K =        $83/usuario

Pero con viral loop (40%):
Effective CAC:              $50/usuario
```

### Lifetime Value (LTV)

**For BASIC tier** ($20/month, 50% of users):
```
Monthly revenue:            $20
Monthly churn:              6% → 5% → 4%
Average lifetime:           18 months (assuming improving churn)

LTV = ARPU × (1 / Monthly Churn Rate) × Gross Margin
    = $20 × (1 / 0.05) × 0.85
    = $20 × 20 × 0.85
    = $340
```

**For PRO tier** ($50/month, 35% of users):
```
Monthly revenue:            $50
Average lifetime:           24 months
LTV = $50 × (1 / 0.04) × 0.85
    = $50 × 25 × 0.85
    = $1,062
```

**For ENTERPRISE** (custom, 15% of users):
```
Average contract value:     $5,000/year ($417/month)
Average lifetime:           36 months
LTV = $417 × (1 / 0.03) × 0.85
    = $417 × 33 × 0.85
    = $11,730
```

**Blended LTV**: 
```
(0.50 × $340) + (0.35 × $1,062) + (0.15 × $11,730)
= $170 + $372 + $1,760
= $2,302
```

### LTV/CAC Ratio

```
Year 1:  $2,302 / $56 = 41:1  ✅ (Healthy: >3:1)
Year 2:  $2,800 / $65 = 43:1  ✅
Year 3:  $3,200 / $50 = 64:1  ✅ (Exceptional)
```

### Payback Period

```
CAC:                        $56
Monthly ARPU:               $30 (blended)
Gross Margin:               85%
Payback = CAC / (ARPU × Gross Margin)
        = $56 / ($30 × 0.85)
        = $56 / $25.50
        = 2.2 months
```

**Interpretation**: Each customer pays back acquisition cost in 2.2 months.

## 📊 ANÁLISIS DE RIESGOS Y MITIGACIÓN

### Riesgo 1: Regulatorio

**Probabilidad**: Media  
**Impacto**: Alto (podrían prohibir operación)

| Riesgo | Mitigación |
|--------|-----------|
| Requerimientos de licencia bancaria | Alianzas con bancos licenciados, no tocamos dinero directamente |
| Privacidad de datos (GDPR, equivalentes) | Cumplimiento desde día 1, DPO designado |
| Seguridad (PCI-DSS) | Tercerizar auth + almacenamiento seguro |

### Riesgo 2: Competencia

**Probabilidad**: Media-Alta  
**Impacto**: Medio (margen erosionado)

| Competidor | Nuestra Ventaja |
|------------|-----------------|
| Fintech grandes (Nubank, Konfío) | Enfoque LATAM específico, simplicidad, IA local |
| QuickBooks/Xero | 10x más simple, costo 75% menor, predicción |
| Contadores | 24/7 disponible, soporte real-time, automatizado |

**Moat defensible**: 
- Datos de 500K+ transacciones LATAM
- Modelos ML entrenados localmente
- Network effects (más usuarios = mejor predicción)

### Riesgo 3: Adopción/Retention

**Probabilidad**: Baja (validado en FASE 2)  
**Impacto**: Alto (negocio no escala)

| Riesgo | Mitigación |
|--------|-----------|
| Usuarios abandonen (churn alto) | UX ultra simple, onboarding de 5 minutos, soporte 24/7 |
| No entienden valor | Educación continua, email drip, calls 1-on-1 |
| Necesitan soporte técnico | Team bilingüe, support en WhatsApp |

**Retention targets**:
- Month 1: >80% (onboarding crítico)
- Month 3: >70% (product-market fit)
- Month 6: >60% (habituación)
- Month 12: >50% (estable)

### Riesgo 4: Dependencia de APIs

**Probabilidad**: Baja-Media  
**Impacto**: Alto (core product breaks)

| Riesgo | Mitigación |
|--------|-----------|
| Yape/Plin cierran API | Contacto directo, acuerdos estratégicos, plan B manual |
| Bancos cierran integración | Diversificación de bancos, legacy support |
| Interrupciones de servicio | SLA > 99.5%, backup systems |
